# ภารกิจลับ 16 ด่าน 💚

เว็บไซต์เซอร์ไพรส์แฟน สร้างด้วย React + Vite ธีมสีเขียว

## วิธีรัน (ใน VS Code)

1. เปิดโฟลเดอร์นี้ใน VS Code
2. เปิด Terminal แล้วรัน:
   ```
   npm install
   npm run dev
   ```
3. เปิดลิงก์ที่ขึ้นมา (ปกติคือ http://localhost:5173)

## Build เป็นไฟล์สำหรับอัปโหลดขึ้นเว็บจริง

```
npm run build
```
ไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์ `dist/` เอาไปอัปโหลดที่ไหนก็ได้ เช่น Vercel, Netlify, GitHub Pages

## โครงสร้างไฟล์

```
src/
  data/gameData.js      -> รหัสฐาน 2 ของแต่ละ "ชุด" + ลำดับกล่องหลัก (แก้ตรงนี้ถ้าอยากเปลี่ยนคำตอบสุดท้าย)
  hooks/useProgress.js   -> จำความคืบหน้า (เก็บไว้ใน localStorage ของเบราว์เซอร์)
  components/            -> ส่วนกลาง เช่น เมนู, กล่องสมบัติหลัก, หน้าเฉลย
  games/Game1.jsx ... Game16.jsx  -> เกมแต่ละด่าน
```

## ⚠️ จุดที่ควรตรวจทานก่อนส่งให้แฟนเล่นจริง

- **เพลงตอนกล่องเปิด**: ตอนกรอกรหัสครบ 25 ช่องถูกต้อง หน้าเว็บจะเปลี่ยนเป็นสีชมพู มีหัวใจร่วงลงมา และเล่นเพลงจากไฟล์ `public/song/perfect.mp3` อัตโนมัติ — ผมใส่เพลงลิขสิทธิ์ "Perfect" ของ Ed Sheeran ให้ในโค้ดไม่ได้ คุณต้องหาไฟล์ mp3 มาเองอย่างถูกต้อง (เช่นซื้อจาก iTunes หรือไฟล์ที่คุณมีสิทธิ์ใช้งาน) แล้ววางไว้ที่ `public/song/perfect.mp3` (ดูรายละเอียดที่ `public/song/README.txt`) ถ้าเบราว์เซอร์บล็อกการเล่นอัตโนมัติจะมีปุ่ม "▶ กดเพื่อเล่นเพลง" ขึ้นมาให้กดแทน
- **เกมที่ 5 (One Piece)** และ **เกมที่ 6 ข้อ 5 (พี่โกฮังชอบกินอาหารประเทศอะไร)**: ผมใส่คำตอบเบื้องต้น/ที่ว่างไว้ให้ (มีคอมเมนต์ `TODO` กำกับในไฟล์ `src/games/Game5.jsx` และ `Game6.jsx`) เพราะเป็นข้อมูลเฉพาะที่คุณน่าจะรู้คำตอบที่ถูกต้องดีที่สุด กรุณาแก้ค่าใน `accept: [...]` ของแต่ละข้อให้ตรงกับคำตอบจริงก่อนใช้งาน
- เกมที่ 7-15 ผมออกแบบให้เป็นมินิเกมง่ายๆ ตามที่ขอ (งู, ไดโนกระโดด, จับคู่ความจำ, ตีตัวตุ่น, ไซมอน, รับของจากฟ้า, OX, จับคู่สี, เขาวงกต) ปรับความยาก/เงื่อนไขผ่านด่านได้ที่ค่าคงที่ด้านบนของแต่ละไฟล์ (เช่น `WIN_SCORE`, `TIME_LIMIT`)
- ระบบจำความคืบหน้าใช้ `localStorage` ของเบราว์เซอร์เครื่องนั้นๆ ถ้าเปลี่ยนเครื่อง/เบราว์เซอร์ หรือกดล้างข้อมูลเว็บไซต์ ความคืบหน้าจะหาย
